# Brent Crude Oil Analysis

I made this project to learn how to work with real financial market data in Python and to explore a few simple ideas around Brent crude during the Iran conflict.

## What is included

- Cleaning and checking more than 1.1 million one-minute Brent observations downloaded from HistData.
- An event study using 14 scheduled Trump events where Iran was a topic. I looked at price movements before and after the events over several time windows.
- A simple Friday-to-Monday test during the Iran conflict to compare holding a position over the weekend with closing on Friday and reopening on Monday.
- Correlation, regression, directional tests and leave-one-out tests.

## What I learned

I learned how to handle a large time-series dataset, clean and check data before using it, and turn an idea about market behaviour into something that can actually be tested. The project also taught me how important statistical testing is when a pattern looks interesting but may just be noise.

I used AI extensively while writing and debugging parts of the Python. This helped me work through problems that I did not already know how to solve and made me much more comfortable learning from unfamiliar code.
